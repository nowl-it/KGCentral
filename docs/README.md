**Game Version**: 167.0.01  
**Data Source**: Reversed from game APK (`data-reverse/` folder)

## Data Limitations

### ✅ Available in data:
- Base stats (Level 1, Tier 1)
- Skill descriptions (all languages)
- Passives (Level 4, 8)
- Awakenings (Level 16)
- Equipment/Altar/Relic effects
- Region synergies

### ❌ NOT in data (hardcoded in game binary):
- Stat growth formula per level
- Tier scaling multipliers
- Exact skill damage values by tier
- Battle damage formulas

See [GAME_MECHANICS.md](game-data/GAME_MECHANICS.md) for detailed explanation.

## Regenerating Data

To update game data after XML changes:

```bash
cd data-reverse
python parse_game_data.py
```

This will regenerate all JSON files in `docs/game-data/`.

## AI Integration

The AI service (`apps/ai-service`) uses this data for:
1. **RAG (Retrieval Augmented Generation)**: Inject hero data into prompts
2. **Language detection**: Auto-detect user language, respond in same language
3. **Partial name matching**: "Luni" → Luniare, "청아" → Chung Ah
